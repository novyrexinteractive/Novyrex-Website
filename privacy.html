2. Allgemeine Informationen zum Spiel

Neon Gunner ist ein mobiles Spiel für Android-Geräte, das von Novyrex Interactive entwickelt wird.

Die geschlossene Beta-Version bietet derzeit keine eigenen Benutzerkonten, keine Registrierung, keine Online-Ranglisten und keine Cloud-Speicherung.

3. Lokale Speicherung von Spielständen

Das Spiel speichert bestimmte Spielinformationen lokal auf dem verwendeten Gerät. Dazu können beispielsweise Spielstände, Coins, Diamanten und Waffen-Upgrades gehören.

Für diese Speicherung wird die Unity-Funktion PlayerPrefs verwendet. Die gespeicherten Werte werden nach unserem derzeitigen Entwicklungsstand nicht an eine eigene Server-Datenbank oder Cloud übertragen.

Die lokalen Daten bleiben grundsätzlich auf dem Gerät, solange sie dort vorhanden sind. Durch das Löschen der App-Daten oder eine Deinstallation können gespeicherte Spielinformationen verloren gehen.

4. Benutzerkonten und Online-Funktionen

In der aktuellen Beta-Version werden keine eigenen Spieleraccounts, Anmeldungen oder Online-Spiel-Funktionen angeboten. Eine eigene Cloud-Speicherung findet nicht statt.

5. Werbung und In-App-Käufe

In der aktuellen Beta-Version werden keine Werbeanzeigen eingeblendet. Es werden außerdem keine In-App-Käufe angeboten.

Für spätere Versionen sind möglicherweise Werbung und In-App-Käufe vorgesehen. Falls solche Funktionen eingebaut werden, wird diese Datenschutzerklärung entsprechend aktualisiert.

6. Technische Daten und Drittanbieter

Neon Gunner wurde mit der Unity-Engine entwickelt. Je nach verwendeten technischen Komponenten und Diensten kann es zur Verarbeitung technischer Informationen kommen.

Dazu können beispielsweise Informationen über das Gerät, das Betriebssystem, die App-Version oder technische Verbindungsdaten gehören.

Die genaue Verarbeitung durch Unity und gegebenenfalls weitere Anbieter muss anhand der tatsächlich verwendeten Komponenten und deren Einstellungen beurteilt werden.

Weitere Informationen zu den Datenschutzpraktiken von Unity: Unity – Game Player and App User Privacy Policy

Die Android-Version enthält eine technische Berechtigung für den Internetzugriff. Das Vorhandensein dieser Berechtigung bedeutet nicht automatisch, dass persönliche Daten übertragen werden.

8. Speicherdauer

Die vom Spiel lokal gespeicherten Informationen bleiben grundsätzlich so lange auf dem Gerät, bis sie gelöscht werden oder die App-Daten beziehungsweise die Anwendung entfernt werden.

Etwaige technische Daten, die durch Drittanbieter verarbeitet werden, unterliegen zusätzlich deren jeweiligen Speicher- und Löschregelungen.
